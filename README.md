# Homebrew Tap for Youty

This repository is the official Homebrew distribution channel for the
[Youty](https://github.com/legetdev/youty) command-line interface. It contains
packaging infrastructure only and is not a separate product.

## Install

```sh
brew install legetdev/youty/youty
```

The formula installs the Youty CLI and the local resources required for
on-device search and indexing. It requires macOS 26 or later and Xcode 26 when
a prebuilt bottle is unavailable.

## Upgrade

```sh
brew upgrade youty
```

Homebrew updates this tap through the standard `brew update` workflow.

## Documentation and support

Product documentation, source code, releases, and issue tracking live in the
[main Youty repository](https://github.com/legetdev/youty).

The macOS app is available from [youtyapp.vercel.app](https://youtyapp.vercel.app).
